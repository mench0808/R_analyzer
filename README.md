R (Shiny) を用いて、アンケートデータ（クアルトリクスの想定）からコンジョイント分析をノーコードで実行・可視化できるアプリです。CSVファイルをアップロードするだけで、部分効用値（Part-worth Utilities）、属性の相対重要度、および統計的有意性を考慮した係数プロット（Coefplot）を自動算出します。
ゼミで皆がローカルで使うことを想定して作ったものなので実際に使用すると不便があるかもしれません。ごめんなさい。

主な機能
多様なデータ形式への対応: 標準的な縦持ちデータに加え、選択型コンジョイント（CBC）の横持ちデータをアプリ内で直接「縦持ち（Long format）」へ変換可能。

充実した前処理・クレンジング: Qualtricsなどのメタデータ行のスキップ、特定列のフィルタリング、変数名のリネーム機能。

回帰モデル:

・線形回帰 (lm)
・ロジスティック回帰 (glm)
・混合効果ロジスティック回帰 (lme4::glmer)
・条件付きロジスティック回帰 (survival::clogit)

可視化とエクスポート:
・信頼区間・p値の有意水準に応じたシェイプ切り替え付き Coefplot
・属性の相対重要度（%）を示すバーチャート
・すべてのプロットのPDFダウンロード機能

画面イメージ
データプレビュー / 編集: アップロードしたデータの型確認、欠損値チェック、縦持ち変換。

分析設定: 被説明変数（Y）や説明変数（X）、基準水準（Reference）、ダミーコード化手法（効果コード化 / トリートメント）の選択。

結果・視覚化: モデル適合度（AIC、決定係数など）、部分効用値テーブル、動的グラフの閲覧。

使用方法（ローカル実行）
1,
リポジトリをクローンまたはダウンロードします。

2,
RまたはRStudioを開き、必要なパッケージをインストールします。

3,
install.packages(c("shiny", "ggplot2", "dplyr", "broom", "tidyr", "lme4", "survival"))
app.R と同一ディレクトリにサンプルデータ（必要に応じて sample_data.csv など）を配置します。

4,
RStudioで app.R を開き、"Run App" ボタンをクリックするか、以下のコードを実行します。

5,
shiny::runApp("app.R")
